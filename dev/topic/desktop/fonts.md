## Naming Convention

`pkgbase`: `font-<fontname>`
`pkgname`: `{ttf,otf}-<fontname>`
`provides`: if old name is required by sime packages

## List of Available Fonts

### Base Fonts

(base ttf fonts are providing `ttf-font`)

- `ttf-dejavu`
- `ttf-noto-fonts`

### CJK Fonts

- `ttf-noto-fonts-cjk`
- `ttf-wqy-microhei`

### emoji Fonts

(emoji fonts are providing `emoji-font`)

- `ttf-noto-fonts-emoji`
